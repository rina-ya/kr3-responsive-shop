Многостраничный учебный каталог из шести растений. Основа — текущая локальная HTML/CSS-версия [КР №1](https://github.com/rina-ya/kr1-html-css-shop), включая её фотографии и контактную информацию. Bootstrap и другие CSS-фреймворки не используются. История нового репозитория начинается с импорта исходной версии, после которого выполнены адаптация и проверка доступности.

Цены и товары демонстрационные. Реальные заказы, оплата и отправка сообщений не выполняются.

Откройте `index.html` двойным щелчком. Все стили, скрипты и изображения локальные, npm для просмотра не нужен.

Для запуска по HTTP из папки проекта:

```powershell
python -m http.server 8003
```

Откройте http://localhost:8003/ . Для остановки нажмите Ctrl+C.

## Адаптивные решения — Mobile First

| Ширина | Поведение |
| --- | --- |
| Телефон, от 360 px | Компактная шапка, нативное меню details/summary, hero и карточки в одну колонку, фильтр над каталогом, формы в одну колонку, характеристики как карточки |
| От 430 px | Две колонки вариантов категории и частей подвала |
| От 640 px | Две карточки в ряду, две колонки полей формы, обычная таблица характеристик |
| От 768 px | Три преимущества и карточки гида, более широкая раскладка подвала |
| От 1024 px | Обычная навигация, hero в две колонки, каталог с боковым sticky-фильтром, три карточки на главной, две в каталоге, двухколоночная страница товара |
| От 1280 px | Расширенные отступы и трёхчастный блок гида |

Базовые правила в `responsive.css` рассчитаны на телефон; расширение идёт через `@media (min-width: ...)`. Старые запросы max-width из первой работы убраны из style.css. Нет глобального overflow-x:hidden, который скрывал бы ошибки раскладки.

- **Flexbox:** действия, шапка desktop, преимущества и части карточек.
- **Grid:** hero, каталог, карточки, формы, контакты и подвал. Используется `minmax(0, 1fr)`, чтобы содержимое не растягивало колонку.
- **Меню:** на телефоне нативный details/summary, управляемый Enter и Space. Desktop-меню показывается с 1024 px. CSS скрывает неактуальный вариант вместе с его ссылками от клавиатуры и дерева доступности.
- **Каталог:** категории переключаются радио-кнопками. `:has(:checked)` меняет видимость подборок без JavaScript; «Все растения» сбрасывает выбор. Фильтр можно свернуть нативным details. На desktop он становится боковым и sticky.
- **Формы:** поля 16 px и высотой от 50 px, крупные подписи и чекбоксы, перенос длинных значений. На телефоне все поля идут в одну колонку.
- **Таблица товара:** до 640 px вместо неё отображается семантический dl со всеми характеристиками. С 640 px показывается исходная таблица. Два варианта не озвучиваются одновременно.
- **Сравнение:** широкая таблица находится в отдельной прокручиваемой области с подписью и tabindex="0"; доступна прокрутка стрелками.
- **Диалог:** вписывается в экран, ограничен по высоте через 100dvh и имеет внутреннюю прокрутку.

## Responsive images

Для всех фотографий используется `picture`: AVIF в source и WebP в img как запасной формат. Для каждого растения сохранены варианты шириной 360, 640 и исходной ширины 736 или 750 px — без увеличения исходника.

`srcset` перечисляет файлы и их настоящую ширину, `sizes` описывает место изображения в hero, карточке или на странице товара. Браузер выбирает подходящий вариант с учётом ширины экрана, DPR и кэша. Также заданы max-width:100%, height:auto, реальные width/height, lazy-loading карточек и fetchpriority="high" для hero.

Исходные PNG занимали 6,13 МБ. Все 36 вариантов AVIF/WebP вместе занимают 1,71 МБ; при просмотре загружается только выбранный вариант. Статистика по растениям — `images/variants.json`. Сами фотографии перенесены из актуальной КР №1, их содержимое сохранено.

Для проверки откройте DevTools → Network, отключите кэш и сравните запросы изображений на разных ширинах и DPR. Можно посмотреть `document.querySelector(".hero__art img").currentSrc`.

## Доступность и исправления

- Ссылка «Перейти к содержимому» переводит клавиатурный фокус на main с tabindex="-1".
- Основные интерактивные элементы имеют область нажатия от 44–48 px, поля формы — от 50 px.
- Видимый фокус оформлен контрастным кольцом; он не скрыт у ссылок и кнопок.
- Сохранены семантические landmarks, порядок заголовков, label/for, required, type=email, alt фотографий, caption/scope таблиц.
- У мобильного меню, фильтра и FAQ используется встроенная семантика details; лишние ARIA-роли не добавляются.
- Модальный dialog получает доступное название, поддерживает Escape, исключает фоновые элементы из порядка Tab и возвращает фокус на кнопку открытия.
- Исправлен контраст счётчика выбранной категории: исходные 4,22:1 не соответствовали порогу 4,5:1 для мелкого текста. Цвет изменён на более тёмный.
- Подпись на hero защищена тёмной подложкой; есть настройки prefers-reduced-motion и prefers-contrast.
- На странице контактов добавлена подписанная форма обратной связи. Обе формы используют нативные проверки и method="dialog", работают без JavaScript и показывают учебный результат без сетевой отправки данных.

## Проверка и самостоятельные доработки

Все 12 страниц проверены на **360, 430, 768, 1024 и 1440 px** — 60 сочетаний страницы и ширины. Общего горизонтального скролла нет. axe-core дополнительно проверил каждую страницу на мобильной и desktop-ширине: нарушений выбранных правил WCAG A/AA не обнаружено.

Доработки сверх основы: нативное мобильное меню, рабочие CSS-категории, сворачиваемый фильтр, мобильные карточки характеристик, AVIF/WebP с несколькими размерами, адаптивная обратная связь, улучшенные размеры элементов и контраст, подтверждённая работа без JS, опубликованные страницы и Lighthouse-отчёты.
